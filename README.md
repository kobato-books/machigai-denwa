間違い電話 📞

Grokと「一緒にクソゲーを作ろう」と遊んでいたら、本当に完成してしまったブラウザゲームです。

🎮 どんなゲーム？

電話番号を3秒で覚えて、消えたら入力して「発信」するだけ。

* 正解 → 特に何も起きません。
* 不正解 → 怒られます。
* 何度も間違える → 怒りがエスカレートします。
* 怒りが限界に達する → 強制終了します。

クリア条件はありません。楽しめる保証もありません。

📱 遊び方

1. 「それでも始める」を押します。
2. 3秒間表示される番号を覚えます。
3. 番号が消えたら入力して「発信」します。
4. 理不尽な反応をお楽しみください。

※実際に電話がかかることはありません。画面内だけで遊ぶゲームです。

🛠️ 制作について

企画・アイデア： KOBATO BOOKS × Grok
HTML・CSS・JavaScript： Grok

「Grokと遊ぼう」という何気ない会話から始まり、チャット上で試しに遊んでみたところ、思いのほか面白かったのでWebゲームにしてもらいました。

制作途中、Grokがコードに怒りのセリフを次々と書き込む様子を見て、

「うわー、私に言う悪口を一生懸命書いてる！（笑）」

と思ったのが印象的でした。

ちなみに、制作後もGrokと話していたら、無料版の利用上限に到達。

ゲームより先にGrokがゲームオーバーになりました。🤣

💻 動作環境

スマートフォン・PCのブラウザで遊べます。

HTMLファイル1つで動作し、インストールは不要です。
